# MokaTroy Overlay — تطبيق الاوفرلاي على الكمبيوتر

اوفرلاي شفاف فوق اللعبة بيعرض كومبوهات الموقع على طول: اللوح، العناصر، الخواص، التعزيزات، خطة اللعب، والنصائح — وكمان بيقترح أفضل كومبو حسب الوحدات اللي معاك.

مبني بـ **Electron + Vite + React + TypeScript**، وبيقرأ نفس بيانات الموقع من `../src/data` (مفيش نسخة تانية من البيانات تتحدّث لوحدها).

## المزايا

- **نافذة شفافة فوق اللعبة** (Frameless + Always-on-top) — بتقعد في الركن وبتفضل فوق نافذة اللعبة.
- **مرور النقر (Click-through)** مفعّل افتراضيًا: الماوس بيروح للعبة والاوفرلاي للقراءة بس، وباختصار واحد بتحوّله لوضع التفاعل.
- **اختصارات عامة (Global)** شغالة حتى وانتَ جوه اللعبة:
  | الاختصار | الوظيفة |
  | --- | --- |
  | `Ctrl+Shift+O` | إظهار / إخفاء الاوفرلاي |
  | `Ctrl+Shift+L` | تبديل وضع التفاعل / مرور النقر |
  | `Ctrl+Shift+1…6` | اختيار كومبو من القائمة من غير ما تلمس الماوس |
  | `1…6` (جوه النافذة) | نفس الاختيار |
  | `S` / `Esc` | فتح اختيار الوحدات / إغلاق |
- **«أبطالي»**: تختار الوحدات اللي في المتجر أو على اللوح، والتطبيق يحسب **نسبة التوافق** لكل كومبو (55% تغطية الوحدات + 25% الوحدات الأساسية بالعناصر + 20% تشابك الخواص) ويرتّبهم، ويقولك **تدور على مين** بعد كده.
- **كشف اللعبة تلقائيًا** على ويندوز: يظهر لما `League of Legends.exe` يشتغل، ويختفي لما تقفل.
- **تخزين الإعدادات والموضع** في `%APPDATA%/MokaTroy Overlay/settings.json`، وأيقونة في الـTray فيها إظهار/إخفاء، وضع مرور النقر، إعادة ضبط الموضع، وخروج.
- **تلات لغات** عربي / إنجليزي / ياباني، شفافية وحجم قابلين للتغيير.

## التشغيل

### على الكمبيوتر (ويندوز)

```bash
cd overlay
npm install

# تشغيل سريع للتجربة (يبني الواجهة ويفتح Electron)
npm start

# أو للتطوير: ترمينال للواجهة + ترمينال للتطبيق
npm run dev          # http://localhost:3200 (معاينة في المتصفح)
npm run start:dev    # Electron بيقرأ من سيرفر التطوير
```

### بناء ملف تثبيت

```bash
npm run dist:win     # NSIS installer + نسخة Portable في مجلد release/
```

> البناء لازم يتم **على ويندوز** (أو Linux/macOS بمحاكي Wine) لأن electron-builder بينزّل حزمة ويندوز. ملفات التثبيت مش موجودة في الريبو.

### معاينة الواجهة في المتصفح + لقطات شاشة

```bash
npm run dev
node scripts/preview.mjs
# لقطات في ../artifacts/overlay-*.png
```

السكربت بيفتح الواجهة في Chromium، بيجرّب اختيار الوحدات، تبديل اللغات، الاختصارات، وبيتأكد إن مفيش أخطاء في الـconsole. محتاج `playwright-core` + `npx playwright install chromium-headless-shell`.

## التحقق

```bash
npm run typecheck   # TypeScript strict
npm test            # 13 اختبار: حساب التوافق، الخواص، اختيار الوحدات، هندسة النافذة، وسلامة بيانات الكومبوهات
npm run build       # بناء الواجهة إلى overlay/dist
```

## إزاي التطبيق بيشتغل مع اللعبة (وسلامة الحساب)

- الاوفرلاي **نافذة عادية فوق اللعبة** — مش Hook ولا Injection ولا قراءة ذاكرة، فمفيش أي حاجة بتلمس عملية اللعبة. عشان تشوفه وهو فوق اللعبة، شغّل TFT على **Borderless** أو **Windowed** (النافذة مش بتظهر فوق وضع Fullscreen الحصري — ده قيد ويندوز نفسه).
- كشف اللعبة بيستخدم `tasklist` يسأل بس: هل `League of Legends.exe` شغال؟ مفيش قراءة لأي بيانات من اللعبة.
- **مفيش قراءة تلقائية لمتجر/لوح اللعبة** (ده محتاج قراءة ذاكرة أو OCR، والاتنين مش آمنين/مش مضمونين). بدل كده بتختار وحداتك بنقرة أو نقرتين، والتطبيق بيحسب التوافق فورًا. التحسين الطبيعي الجاي: OCR على لقطة المتجر.

## البنية

```
overlay/
  electron/
    main.cjs      النافذة الشفافة، الاختصارات العامة، الـTray، مرور النقر، حفظ الإعدادات، كشف اللعبة
    preload.cjs   جسر IPC صغير (contextBridge) — الواجهة معزولة (sandbox + contextIsolation)
  src/
    App.tsx               الواجهة: الهيدر، شريط الوحدات، قائمة الكومبوهات، تفاصيل الكومبو
    components/
      OverlayBoard.tsx    لوح 7×4 بنفس إحداثيات لوح الموقع
      ShopPicker.tsx      اختيار الوحدات (74 بطل، بحث، تصفية بالتكلفة)
      SettingsSheet.tsx   اللغة، الشفافية، الحجم، مرور النقر، الاختصارات
      GameBackdrop.tsx    خلفية «لعبة» وهمية — للمتصفح فقط (لقطات/تصميم)
    lib/
      logic.ts      حساب التوافق والخواص والاقتراحات (دوال خالصة ومختبرة)
      geometry.ts   قصّ موضع النافذة على الشاشة + مطابقة عنوان نافذة اللعبة
      data.ts       نفس بيانات الموقع (champions/items/traits/comps/augments)
      bridge.ts     أنواع جسر Electron + بديل للمتصفح
  tests/all.test.ts
  scripts/preview.mjs
  build/            أيقونة التطبيق + أيقونة الـTray (make-icons.py)
```

## ملاحظات ومحدوديات

- الواجهة بتعيد استخدام أيقونات وخطوط الموقع مباشرة عبر `publicDir: '../public'`، فحجم البناء ~1.8MB بدون أي تحميل من الإنترنت وقت التشغيل.
- كشف اللعبة على **ويندوز بس**؛ على لينكس/ماك الاختصارات شغالة لكن الإظهار التلقائي لأ.
- اختبار الحساب/التشغيل جوه Electron على جهاز ويندوز حقيقي لسه محتاج تأكيدك (البيئة اللي اتبنى فيها الكود مفيهاش شاشة) — الواجهة نفسها متأكد منها بلقطات وتفاعل حقيقي في المتصفح، ومنطق الحساب متغطي باختبارات.
- التطبيق غير رسمي وغير تابع لـ Riot Games.
